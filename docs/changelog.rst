Changelog
=========

The full per-release changelog lives at `CHANGELOG.md
<https://github.com/pediapress/mwlib/blob/main/CHANGELOG.md>`_ in the
repository root. It is rendered there by GitHub and tracks every release
back to 0.9.5.

Rendering Markdown inside this Sphinx tree would require adding
``myst-parser`` to ``docs/conf.py`` extensions; until that's wired up,
this page is a pointer rather than an inline copy.
